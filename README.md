# DerpMeter Homebrew tap

```sh
brew tap derpmeter/derpmeter
brew install derp                  # CLI: derp status, derp vote, statusline, MCP
brew install --cask derpmeter      # macOS menu bar app (macOS 14+)
```

See https://derpmeter.com/apps. The CLI is also on npm: `npm install -g derpmeter`.
